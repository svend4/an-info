# an-info

Вики о компании Anthropic, которую собирает и поддерживает языковая модель по паттерну «LLM wiki» Андрея Карпаты: неизменяемый слой сырых фактов, слой русскоязычных страниц и схема правил.

**Начать чтение:** [wiki/index.md](wiki/index.md) → [Anthropic Public Benefit Fund](wiki/anthropic-public-benefit-fund.md).

## Как устроено

| Папка или файл | Что внутри |
|---|---|
| [`wiki/`](wiki/) | Страницы на русском. Каждое утверждение снабжено ссылкой на факт вида `F017` и значком статуса проверки. |
| [`raw/`](raw/) | Сырые факты в том виде, в каком их собрали агенты: формулировка на английском, источник, дата, цитата, результаты проверок. Не редактируется. |
| [`CLAUDE.md`](CLAUDE.md) | Схема вики: слои, правила ID, легенда статусов, операции ingest / query / lint. |

## Легенда статусов

✅ проверено двумя независимыми проверками · ⚠️ спорно · 🔴 не подтверждено · 🟢 первоисточник (Anthropic или оригинальный пост автора) · 🟡 крупное СМИ · 🟠 вторичный источник · ⚪ оценка или мнение

Статус показывает, насколько факт проверен, а не истинен ли он. Подробнее в [CLAUDE.md](CLAUDE.md).

## Текущее состояние

Первая тема: Anthropic Public Benefit Fund, объявленный 18 октября 2026 года. Загружено 320 фактов по семи направлениям; независимая двойная проверка завершена для первых 25 фактов, остальные несут статус по типу источника. План дальнейшей проверки описан в [wiki/log.md](wiki/log.md).
