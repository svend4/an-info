# Схема вики `an-info`

Этот репозиторий устроен по паттерну «LLM wiki» (Андрей Карпаты, 2026): человек приносит источники, языковая модель строит и поддерживает связную вики из Markdown-страниц, а не отвечает каждый раз «с нуля» по сырым документам. Файл, который вы читаете, и есть схема: правила, которым следует любой агент, работающий с репозиторием.

Тема вики: компания Anthropic. Первая тема, заведённая в вики: Anthropic Public Benefit Fund (октябрь 2026).

## Три слоя

| Слой | Путь | Кто пишет | Правило |
|---|---|---|---|
| Сырые данные | `raw/` | только скрипты сбора | Неизменяемый. Файлы не редактируются после записи. Факты хранятся на языке сбора (английский) со стабильными ID. |
| Вики | `wiki/` | языковая модель | Русскоязычные страницы, которые цитируют факты по ID. Правки и уточнения делаются здесь. |
| Схема | `CLAUDE.md` | человек и модель вместе | Этот файл. Меняется редко. |

Полные копии чужих статей в `raw/` не хранятся: репозиторий публичный. Хранятся утверждения, ссылки, даты и короткие цитаты.

## Факты и их ID

- Каждый факт имеет ID вида `F001`. ID выдаётся один раз при сборе и больше не меняется и не переиспользуется.
- Факт живёт в одном файле слоя `raw/` и имеет одну «домашнюю» страницу вики, где он приведён целиком как отдельный пункт списка: `- **[F017]** 🟡 Текст. — Источник: …`.
- Любая другая страница может ссылаться на факт по ID без повторения текста.
- Если факт оказался ошибочным, его текст в `raw/` не трогают. На домашней странице меняют значок статуса, добавляют подпункт «Проверка: …» и пишут запись в `wiki/log.md`.

## Статусы проверки

| Значок | Статус | Значение |
|---|---|---|
| ✅ | Проверено | подтверждено двумя независимыми проверками: по указанному источнику и по независимому источнику |
| ⚠️ | Спорно | одна из двух проверок не подтвердила |
| 🔴 | Не подтверждено | проверка опровергла или источник не найден |
| 🟢 | Первоисточник | взято из публикации Anthropic; отдельная проверка не проводилась |
| 🟡 | Крупное СМИ | Reuters, AP, Bloomberg, CNBC, Forbes, Коммерсантъ, РБК и подобные; независимая проверка не проводилась |
| 🟠 | Вторичный источник | агрегатор, блог, пересказ, машинный перевод; требует проверки |
| ⚪ | Оценка или мнение | предположение, интерпретация, прогноз, расчёт самого издания |

Статус описывает степень проверки, а не истинность. Факт 🟡 может быть верным, факт ✅ может устареть.

## Страницы вики

Обязательные служебные страницы:

- `wiki/index.md` — оглавление: список всех страниц с аннотацией в одну строку, легенда статусов, счётчики. Обновляется при каждом изменении набора страниц.
- `wiki/log.md` — журнал: что и когда добавлено, какие источники загружены, какие ошибки найдены и исправлены. Только дописывается, записи не удаляются.
- `wiki/glossary.md` — глоссарий терминов с английским оригиналом и вариантами перевода.

Структура тематической страницы: H1 заголовок; лид из нескольких предложений; строка со ссылкой на легенду; тематические разделы с фактами-пунктами; разделы «Противоречия и слабые места», «Открытые вопросы», «Связанные страницы», «Источники».

Главная страница темы (например, `wiki/anthropic-public-benefit-fund.md`) — связный текст-синтез, который цитирует факты по ID и ведёт на тематические страницы.

## Правила текста

- Язык вики русский. Названия организаций, фондов, документов и имена людей при первом упоминании даются с оригиналом в скобках: Дарио Амодей (Dario Amodei).
- Цитаты приводятся дословно на языке оригинала. Перевод цитаты, если нужен, идёт после неё и помечается как перевод.
- Числа, даты и имена берутся только из источников. Если число есть лишь в одном источнике, это пишется прямо. Собственная арифметика помечается как расчёт.
- Оговорки источников («по сообщениям», «по словам», «предположительно») сохраняются при переводе.
- Противоречия между источниками фиксируются с ID обеих сторон, «правильная» версия не выбирается молча.
- Anthropic Public Benefit Fund не называть «благотворительным фондом»: компания выбрала форму LLC, а не благотворительную организацию 501(c)(3), и сама этого слова избегает. Допустимые русские варианты: «Фонд общественного блага», «Фонд общественной пользы».

## Операции

**Ingest (загрузка).** Новый источник или новая партия фактов: записать в `raw/` новый файл с датой в имени, не трогая старые; выдать новым фактам следующие свободные ID; разнести факты по домашним страницам или создать новую страницу; обновить `index.md`; дописать `log.md`.

**Query (вопрос).** Отвечать по страницам вики, цитируя ID. Если ответ потребовал чтения `raw/` или внешних источников и получился полезным, оформить его новой страницей или разделом и записать в журнал.

**Lint (проверка здоровья).** Регулярно, и обязательно после каждой загрузки: каждый ID присутствует на своей домашней странице ровно один раз; значок на странице совпадает с `raw/`; все относительные ссылки ведут на существующие файлы; нет страниц без входящих ссылок; противоречия перечислены в соответствующих разделах; устаревшие формулировки («в ближайшие месяцы», «ожидается») помечены датой, на которую они верны.

**Verify (дополнительная проверка).** Факты со статусами 🟢 🟡 🟠 ⚪ можно переводить в ✅ или 🔴 отдельными проходами. Для экономии ресурсов такие проходы запускаются на более дешёвой модели, по одному проверяющему на факт, и только для фактов, которые реально используются на главных страницах.

## Как с этим работать человеку

Удобнее всего открыть папку как хранилище Obsidian: ссылки между страницами относительные, граф связей строится автоматически. На GitHub всё тоже читается, начиная с `wiki/index.md`.
